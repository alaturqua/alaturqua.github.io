  • dbt Slim CI

    Pull request builds that run and test only the models that changed.

    dbt · Databricks
    More

    Pull request runs compare against the production manifest and build only modified models and what depends on them (state:modified+), so CI stays fast as the project grows. Write-up: dbt Core and Slim CI on Databricks. Related open source: dbt-hodor.

  • dltHub ingestion framework

    A reusable ingestion framework on dlt for bringing new sources into the lakehouse.

    Allianz Partners
    More

    Ingestion on dlt (dltHub) that brings sources into the Databricks lakehouse at Allianz Partners, with dbt handling transformation downstream.

  • AI functions for Trino

    A Trino/Starburst plugin that exposes LLM calls as SQL functions, shown on Trino Community Broadcast 60.

    Open source · trino-ai
    More

    LLM calls exposed as SQL functions in Trino/Starburst, so models can be used from plain SQL. Code: trino-ai. Demo: Trino with Llama 3 on LinkedIn and Trino Community Broadcast 60.
